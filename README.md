# FRecorder

**FRecorder** 是一款快速、直接的 Android 外景录音应用。

  <img src="shot-quick-mic.jpg" width="300" alt="内置麦克风快捷录音"/>
</p>

## 改动

- **收音设备显式选择**——音频输入列表现在包含系统上报的全部输入。
- **内置麦克风快捷录音**——长按应用图标独立入口（设置 → *使用内置麦克风快捷录音*），快速使用内置麦克风录音。
- **完整简体中文本地化**——所有字符串均已翻译。
- **修改显式选中内置麦克风时的啸叫风险判定**

## 功能

- 除上述改动外，其余功能无变动，请参照 [vdo/FRecorder](https://github.com/vdo/FRecorder)
